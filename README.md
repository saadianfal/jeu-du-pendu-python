# 🪓 Jeu du Pendu en Python

Un jeu interactif du pendu en ligne de commande développé en Python.

## 🌟 Fonctionnalités

- 🎯 **Niveaux de difficulté** : Mots choisis au hasard selon le niveau sélectionné (facile, moyen, difficile).
- 🔤 **Affichage dynamique** : Progression du mot avec les lettres devinées (ex: `_ a _ _ _`).
- 🎨 **Dessin ASCII** : Graphisme évolutif du pendu à chaque erreur.
- 🚫 **Gestion des erreurs** : Saisie invalide refusée (chiffres, plusieurs caractères ou lettres déjà jouées).
- 🧹 **Normalisation des accents** : Prise en compte des caractères accentués.

## 🚀 Comment lancer le jeu ?

1. Assurez-vous d'avoir **Python 3** installé sur votre machine.
2. Téléchargez ou clonez le fichier `pendu.py`.
3. Lancez le jeu dans votre terminal avec la commande :

```bash
python3 pendu.py
